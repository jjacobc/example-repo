# Task Manager

A command-line task management program for a small team, written in
Python. Users log in with credentials stored in user.txt, then add
tasks, view all tasks or just their own, mark their tasks complete
and edit them. Tasks are stored in tasks.txt.

Admin users can also register new users, view completed tasks and
delete tasks. Both admin and standard users can generate reports and
display statistics covering task completion and per-user workload.

## Running it

    python3 task_manager.py

The default login is username "admin" with password "adm1n".
